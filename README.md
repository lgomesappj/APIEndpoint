# APIEndpoint

Optimizes asynchronous microservice interactions through a secure, stateless request-response gateway supporting CORS protocols.

APIEndpoint is built to be simple and practical, focusing on doing one thing well.

**Why APIEndpoint?**

- Optimizes asynchronous microservice interactions through
- a secure, stateless request-response gateway
- supporting CORS protocols

## Key Features

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/APIEndpoint.git`
2. `cd APIEndpoint`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
